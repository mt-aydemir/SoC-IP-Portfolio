# fft

Burst radix-2 FFT/IFFT of `2**N_LOG2` complex points: load a frame, transform it
in place with one butterfly per cycle, unload it in natural order.

```
X[k] = (1/N) * sum over n of x[n] * exp(-+ j*2*pi*n*k/N)
```

The minus sign is the forward transform; a frame loaded with `inverse` high
uses the plus sign. The fixed 1/N scaling, a halving per stage, keeps the
arithmetic in range and makes the inverse exact in scale.

| | |
|---|---|
| **Category** | `dsp` |
| **Top module** | `fft` (with `fft_twiddle`) |
| **Clock domains** | 1 (`clk`) |
| **Reset** | `rst_n`, active low, async assert / sync release |
| **Frame time** | `N` load + `(N/2) * N_LOG2` compute + `N` unload cycles |
| **Verified at** | `N_LOG2=5 DATA_WIDTH=12`; `N_LOG2=4 DATA_WIDTH=10` in the SV testbench |

## Interface

| Signal | Dir | Width | Description |
|---|---|---|---|
| `s_valid` / `s_ready` | in / out | 1 | Input handshake, `N` samples per frame |
| `s_re`, `s_im` | in | `DATA_WIDTH` | Signed input sample |
| `inverse` | in | 1 | Sampled with each frame's first sample |
| `m_valid` / `m_ready` | out / in | 1 | Output handshake |
| `m_re`, `m_im` | out | `DATA_WIDTH` | Output bin, natural order |
| `m_last` | out | 1 | Bin `N-1` |
| `m_overflow` | out | 1 | A butterfly in this frame saturated |

Twiddles are Q1.15, read from `rtl/fft_twiddle.sv`, a quarter-wave ROM
generated by `scripts/gen_twiddle.py` (`--check` verifies it is current).

## Parameters

| Parameter | Type | Default | Range | Effect |
|---|---|---|---|---|
| `N_LOG2` | `int unsigned` | 6 | 3 to 10 | Transform size, `N = 2**N_LOG2` |
| `DATA_WIDTH` | `int unsigned` | 16 | 4 to 24 | Width of each real and imaginary part |
