# Changelog

All notable changes to `fft` are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this IP is versioned independently under
[Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **major** — an incompatible change to ports, parameters or protocol
- **minor** — a backwards-compatible feature or new parameter
- **patch** — a bug fix or documentation change with no interface change

## [Unreleased]

### Changed

- The twiddle ROM is left out of code coverage with `verilator coverage_off`: it is
  data, not control flow. A comment-only change.
  `scripts/gen_twiddle.py` emits the pragmas.

## [1.0.0] - 2026-11-01

### Added

- Initial release.
- Burst radix-2 decimation-in-time FFT and IFFT, 8 to 1024 points, in place
  with one butterfly per cycle and natural-order output.
- 1/N scaling by a rounded halving per stage, saturation per butterfly and a
  per-frame `m_overflow` flag.
- Quarter-wave Q1.15 twiddle ROM, `fft_twiddle`, generated by
  `scripts/gen_twiddle.py`, with a `--check` mode.
- cocotb suite with a bit-exact model and numpy comparison; self-checking
  SystemVerilog testbench against a direct DFT in real arithmetic.
- Documentation and timing constraints.
